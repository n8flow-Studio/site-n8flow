# Assets de marca N8FLOW

Adicione apenas arquivos oficiais autorizados:

```text
logo.svg
logo-dark.svg       # se existir versão oficial
logo-light.svg      # se existir versão oficial
symbol.svg          # se existir símbolo oficial
favicon.svg
og-default.png
```

Não crie, redesenhe, distorça ou recolora a logo por inferência. Variante ausente deve ser registrada como pendência.
