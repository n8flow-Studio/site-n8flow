# Assets de marca N8FLOW

Derivados dos arquivos oficiais fornecidos pelo responsável em 28/08/2026, sem
redesenho ou alteração das cores `#00F5A0` e `#6E44FF`.

- `logo.svg` e `logo.png`: assinatura completa em fundo transparente.
- `logo-light.*` e `logo-dark.*`: mesma assinatura oficial, nomeada conforme o
  contexto de aplicação; não houve recoloração inferida.
- `symbol.svg` e `symbol.png`: símbolo isolado em fundo transparente.
- `favicon.svg`, `favicon.png` e `favicon-32x32.png`: favicons transparentes.
- `apple-touch-icon.png`: símbolo sobre o fundo oficial `#2E2E3A`.
- `og-default.png`: imagem social 1200 × 630 em fundo light-first.

Os SVGs encapsulam os pixels oficiais para máxima fidelidade porque não foi
fornecido um arquivo vetorial de origem. Para vetores editáveis e escaláveis sem
limite, substitua-os futuramente pelos arquivos mestres exportados do software
de design, mantendo estes nomes.
