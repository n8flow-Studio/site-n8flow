# Pacote Antigravity — Site N8FLOW

**Versão do pacote:** 1.0  
**Data:** 2026-08-18

## Instalação

Copie **todo o conteúdo desta pasta** para a raiz do workspace vazio no Antigravity. O arquivo `AGENTS.md` deve ficar na raiz, ao lado de `docs/` e `public/`.

Depois da cópia, peça ao agente para ler `AGENTS.md` e `docs/README.md` antes de criar o projeto.

## Conteúdo

- `AGENTS.md`: contrato permanente dos agentes.
- `docs/product/`: requisitos de produto.
- `docs/ux/`: UX e arquitetura de informação em Markdown validado.
- `docs/design-system/`: Design System modular.
- `docs/copy-conteudo/`: copy, formulários, FAQs, CTAs e metadata.
- `docs/arquitetura-tecnica/`: arquitetura de implementação.
- `docs/decisions/`: ADRs.
- `public/brand/`: local reservado aos assets oficiais.

## Importante

A pasta não contém credenciais nem assets de marca inventados. Adicione os arquivos oficiais em `public/brand/` antes do go-live. Os documentos em Markdown são a fonte de verdade do desenvolvimento.
